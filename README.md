Покрыто тестами:

add_new_book добавление, границы длины (0, 40, 41), дубликат
set_book_genre / get_book_genre установка жанра, недопустимый жанр, книга без жанр
get_books_with_specific_genre: поиск по жанру, пустой результат, несуществующий жанр
get_books_genre: возврат словаря
get_books_for_children: исключение жанров с возрастным рейтингом, книга без жанра
add_book_in_favorites: добавление, отсутствие книги, дубликат
delete_book_from_favorites удаление
get_list_of_favorites_books пустой список изначально
